# Frontiers-FPS
Frontiers-FPS is a Doom-inspired first-person shooter set in a medieval era, developed as part of the Frontiers project for the HBO Saxion CMGT program.

The game combines fast-paced, old-school FPS combat with unconventional weaponry such as swords and bow-and-arrow combat, creating a unique gameplay experience within a demonic medieval setting.

The project was developed by a team of seven students, with all art assets and engineering fully created in-house. No downloaded or copied assets were used, ensuring complete originality and professional production standards.

# Gameplay Focus

. Classic fast-paced FPS combat inspired by Doom 3

. Medieval weapons in a demonic setting

. Emphasis on responsiveness, movement, and combat flow
