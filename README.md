# Frontiers-FPS
A doom like first person shooter in the medival time era with demonic creatures for the Frontiers project in HBO Saxion CMGT study. We focused on a classic old school Doom 3 type of gameplay with swords and a bow and arrow because it plays in a different timeline. The project is made by 7 people (myself included). We all worked on the Art Designs and Engineering parts ourseleves with no downloaded or copied Art everything is originally made which makes our project much more proffessional and stand out!
